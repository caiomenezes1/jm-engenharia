# Diário de Obras - JM Engenharia

MVP de uma aplicação web desktop para auxiliar no preenchimento e na geração do diário de obras da JM Engenharia.

## Objetivo

Simplificar o registro diário das informações da obra, incluindo profissionais, quantidades, atividades executadas e observações, permitindo gerar um documento editável em Word.

## Tecnologias previstas

- Python 3.12
- Flask 3.1
- SQLAlchemy 2.0
- PostgreSQL 18
- HTML5, CSS3 e Bootstrap 5.3
- python-docx 1.2

## Ambiente de desenvolvimento

Aplicação planejada para execução local em computador, utilizando navegador web.
